# Content System — Wajdan

Research base and reel scripts for Wajdan's organic content.

| Folder | What's in it |
|---|---|
| `research/` | The creator list, format library, playbook, ad swipe, spec and workflow |
| `research/scripts/` | Locked, shoot ready scripts |
| `deliverables/` | PDFs for Wajahat |

**Start with `research/WORKFLOW.md`.** It explains how the system runs, what each tool is for
and what it costs.

`research/creators.md` is the single source of truth for who to model. Nothing else should
hold a creator list.

## Tools in use
- **vidIQ** — discovery only. 150 free credits a month, refills on the 24th.
- **Apify** — monitoring and teardowns. Free $5 a month. Credential saved on the `wajdann`
  cloud environment, so any session there has it.
- **Meta Ad Library** — paid ad headlines. Free and unlimited through the connector.
