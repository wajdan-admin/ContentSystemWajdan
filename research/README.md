# Wajdan Research Base
Permanent asset. Discovery is paid for once; monitoring is cheap forever.

| File | What's in it |
|---|---|
| `creators.md` | Locked creator list — 12 Tier A (model these), 9 Tier B (benchmark) |
| `formats.md` | Winning formats, hook patterns, length finding, CTA standard |
| `meta-swipe.md` | Competitor ad headlines, longest-runners, page_ids to monitor |
| `ideal-profile.md` | The locked spec + 7-point scoring test |

## How to refresh (no rediscovery)
- **Paid ads:** re-query the page_ids in `meta-swipe.md`. Free, unlimited, via the Meta connector.
- **Organic:** pull the Tier A handles' recent reels. ~5 credits each on vidIQ, or ~$1.20/mo via Apify for all of them.
- **Re-run full discovery only when entering a genuinely new niche.**

## Cost model
| Layer | Cost |
|---|---|
| Meta Ad Library | $0, unlimited |
| vidIQ Free | $0 — 150 credits/mo, renews |
| Apify monitoring (optional) | ~$1.20/mo |

## Caveats
- Meta Ad Library has **no spend or performance data**. Longevity and variant count are proxies, not measurements.
- 500K+ view threshold in B2B pulls some adjacent general-business content. Tier A is filtered for relevance.
- Follower counts and medians are snapshots from 2026-11-25.
