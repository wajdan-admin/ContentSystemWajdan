# Swipe File
**Reels Wajahat or Danyal flagged as good.** Paste a link, it gets logged here.

---

## How this works

**You:** paste a reel link, in any session, with or without a reason.

**Claude:**
1. Logs it below straight away. Free, no analysis.
2. Asks whether you want it broken down.
3. If yes, runs an Apify teardown (~$0.19) for the transcript and scene structure, then fills in
   the format and the hook.
4. When a script gets built from it, marks it and links the script.

**Status values:** `inbox` not looked at yet · `analysed` torn down · `built` a script exists

> For this to work from a phone, the session needs this repository attached. Without it the link
> can still be discussed, but nothing persists.

---

## Patterns so far

Across what has been liked, three things repeat:

1. **A named structure.** A rule with numbers in it, or a format with a clear shape.
2. **No studio.** Filmed in a car, at a desk, one take, on a phone.
3. **A single idea, fully landed**, rather than a list of tips.

What has been rejected: abstract concept words that need defining, anything that reads as a pitch,
and trios of synonyms dressed up as a framework.
